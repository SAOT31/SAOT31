### 👨‍💻 About Me
I used to measure a company's success by analyzing its balance sheets; now, I help drive it by building the software behind it. Transitioning from accounting to software development has allowed me to understand the 'why' of the business, not just the technology. I write code with a focus on delivering real value, knowing that a useful contribution makes someone's day-to-day life easier. 

When I'm offline, I love discovering new cultures and landscapes. To me, traveling is like learning a new programming language—it changes the way you think and gives you a broader perspective on how to solve everyday problems.

- 🎓 **Currently focusing on:** Advanced C#, ASP.NET Core, and system architectures.
- 💼 **Experience with:** JavaScript, Python, C#, SQL/NoSQL, and REST APIs.
